## Option A — Run locally (Python)

```bash
# 1. Create and activate a virtual environment
python -m venv venv
source venv/Scripts/activate        # Windows Git Bash
# source venv/bin/activate           # macOS / Linux

# 2. Install dependencies
pip install -r requirements.txt

# 3. Set your API key
export API_KEY="choose-something-long-and-random"

# 4. Start the server
python app.py
```

Then open http://localhost:5000/ in your browser for the HTML form,
or use curl from a second terminal:

```bash
# Health check
curl http://localhost:5000/health

# Single prediction
curl -X POST http://localhost:5000/predict \
     -H "Content-Type: application/json" \
     -H "X-API-Key: choose-something-long-and-random" \
     -d @sample_request.json

# Batch prediction
curl -X POST http://localhost:5000/predict_batch \
     -H "Content-Type: application/json" \
     -H "X-API-Key: choose-something-long-and-random" \
     -d '[<record1>, <record2>]'
```

## Option C — Render.com (cloud, free tier)

1. Push this folder to a private GitHub repository
2. Go to dashboard.render.com → New → Web Service → connect the repo
3. Render auto-detects `render.yaml` and builds the Docker image
4. After deploy, find your `API_KEY` in the Environment tab

## API Reference

### GET /health
No auth required. Returns model status.

### POST /predict
Auth: `X-API-Key` header required.

Request body (all 17 fields required):
```json
{
  "age": 28,
  "age_group": "25-29",
  "county": "Turkana",
  "residence_type": "Rural",
  "education_level": "Primary",
  "religion": "Roman Catholic",
  "household_size": 6,
  "household_head_sex": "Male",
  "wealth_index": "Poorest",
  "children_ever_born": 3,
  "age_first_birth": 19,
  "living_children": 3,
  "pregnancy_loss": "No",
  "marital_status": "Married",
  "union_status": "Currently in union",
  "partner_education": "Primary",
  "currently_working": "No"
}
```

Response:
```json
{
  "prediction": "No method",
  "probabilities": {
    "Folkloric": 0.0003,
    "Modern": 0.406,
    "No method": 0.522,
    "Traditional": 0.0717
  },
  "risk_flag": "non_use_risk"
}
```

`risk_flag` is `"non_use_risk"` when predicted class is "No method",
otherwise `"using_method"`.

### POST /predict_batch
Same auth. Body is a JSON array of respondent records.
Returns `{ "count": N, "results": [...] }`.
